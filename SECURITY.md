# Security policy

## Supported versions

FlyVista is currently in alpha. Security fixes are applied to the latest published alpha release and the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature after the repository is created. Do not disclose an exploitable issue in a public issue before a fix is available.

Reports should include the affected version, operating system, reproduction steps and expected impact. Do not include passwords, signing keys or unrelated personal information.
