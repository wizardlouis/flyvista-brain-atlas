# Contributing to FlyVista

Thank you for helping improve FlyVista.

1. Open an issue before starting a large behavioral or data-model change.
2. Create a focused branch such as `feature/region-search` or `fix/camera-reset`.
3. Run `pnpm check` before opening a pull request.
4. For desktop changes, also run `cargo check --manifest-path src-tauri/Cargo.toml`.
5. Explain user-visible changes and data-provenance changes in the pull request.

Contributions to the source code are submitted under Apache-2.0. Do not add data unless its redistribution terms are documented and compatible with the project. Never commit credentials, signing certificates or notarization keys.
